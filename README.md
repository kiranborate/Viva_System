# Viva_System
Smart Viva System is a web-based viva practice platform designed for students to practice oral exam questions interactively.


## ✨ Features
- 🎯 Subject selection dashboard
- 🎤 Viva practice interface
- 🔄 Random question generator
- 📊 Result page
- 📱 Responsive UI
- 🎨 Glassmorphism design
- ⚡ Fast loading
- 🧠 Multiple subjects support
- 📝 Answer input field
- 🔁 Practice again option
- 🚀 Simple & lightweight


## 📚 Subjects Included
- Mobile Application Development
- Blockchain Technology
- Angular JS
- Java Programming


## 🛠 Technologies Used
- HTML5
- CSS3

## ▶️ How to Run
1. Install XAMPP / WAMP
2. Copy project to `htdocs`
3. Start Apache
4. Open browser
5. Run `dashboard.html`


## 📂 Project Flow
Dashboard → Subject Selection → Practice → Result
